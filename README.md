# Clown Circus Reloaded

**Clown Circus Reloaded** is a brownfield reimplementation of [Clown Circus Carnival](https://github.com/lucapug/clown-circus-carnival), my 2025 capstone project for the first edition of the AI Dev Tools Zoomcamp.

The original project was already a successful experiment in AI-assisted software development. At a time when agent teams, engineering loops, graph-based workflows and other agentic patterns were still emerging, I built a manually orchestrated team of LLMs with distinct roles, responsibilities and development boundaries.

One year later, the second edition of the course presents a substantially more mature set of AI-assisted software engineering practices: structured agent workflows, persistent context, rules, skills, commands, MCP, automated verification, guardrails and other forms of AI-native development.

This project is an opportunity to revisit the same product with that new toolbox.

Rather than simply continuing the original codebase, I will reimplement and evolve the game from the existing 2025 artifact, while redesigning the development process around the practices and techniques presented in the 2026 course.

The original implementation therefore serves both as a **reference implementation and a baseline**. The goal is not to reproduce it exactly: bugs may be fixed, architectural decisions revisited, and new features introduced where appropriate.

The interesting question is not simply *how to build Clown Circus again*, but:

> **What changes when a project that was already developed with AI assistance is rebuilt one year later using a more mature AI-native software engineering approach?**
